# 分则：数据与配置

本页为有效方法；先读[通则与索引](../需求理解与验收经验.md)。配置永久要求以[AGENTS](../../AGENTS.md)为准，本页记录如何识别和验证遗漏。

<a id="d01"></a>

## D01 配置传播闭环

**检索词**：保存、勾选、导出、导入、换设备、迁移、丢失、重启、实际生效、人数、重排、空岗无报警、后续不生效、跨页面、缓存、只改一处。

**适用**：设置、输入、规则或数据会被其他页面、操作或后续阶段使用；包括新增开发、维护修改和反复出现的“保存正确但结果不符”，不限于排班或某个按钮。

**易错**：把控件值、保存回执或导入字段存在当成实际生效；只修一个入口，遗漏共享消费者；新建环境正常而已有草稿、缓存、历史或恢复状态仍用错数据；让实现与测试共同假定“旧值就是主动例外”。

**做法**：在原计划或传播矩阵记录“输入事实→保存位置→相关操作/消费者→实际采用值与生效时机→用户结果→验证证据”。沿真实调用和读写路径确认影响面，检查受影响的保存、计算、人工修改、归档、展示、导入导出、恢复及重开；不适用项写原因。主动制造新旧值不一致、修改已有数据、关闭/清空和失败重试等状态，观察每条路径最终用了什么。持久设置再走导出→空环境导入→重启→实际使用。数据来源与例外按[D02](#d02)，缺失对象按[V04](验证与交付.md#v04)核对。

**完成标准**：每个受影响消费者的实际值和效果都有证据，未验路径明确列出；组别/临时例外不串，内部ID变化不丢归属。既验证应变化的结果，也验证应保持的历史和例外，修复范围与完成声明一致。

**证据**：[E06 保存入口漏消费字段](../../history.md#lesson-e06)、[E07 换设备勾选核查](../../history.md#lesson-e07)、[E10 配置人数未进入重排且缺岗漏报](../../history.md#lesson-e10)、[E11 跨入口共因的通用检查](../../history.md#lesson-e11)。E06当时的相对时间产品方案可能已被替代，本条只保留字段传播教训；E07未查到迁移遗漏，不能写成已发生丢数事故。

## D02 数据层次与旧格式语义

**检索词**：默认值、缺字段、空列表、关闭、旧格式、兼容、长期/当天、草稿、正式、历史快照。

**适用**：格式或规则升级、载入长期配置、恢复历史，以及新旧页面同时存在。

**易错**：缺字段被当成清空，显式关闭被默认值重新开启；长期配置覆盖当天例外或旧正式；新接口让旧页面按旧含义写入成功。

**做法**：逐项约定缺字段、空值、显式关闭和空集合的含义；分别追踪长期、当天、草稿与正式的更新入口。不能把旧快照的存在直接解释为用户主动设置的例外；当前设置和旧值冲突时，按用户期望明确默认来源及保留临时例外的操作入口，不让用户猜还需另点一次载入。正反设置分组验证，旧页面/旧文件分开制定兼容策略；采用原子保存或拒绝，保留用户原资料。

“用最新值”不是所有场景的通则：历史、已确认快照和明确临时例外可能应保留原值。每个消费者按已确认的业务含义选择来源；缓存只能复用仍有效的结果。未知来源优先级按AGENTS提问，不能从某次修复推广出全局覆盖策略。

**完成标准**：旧格式保留/默认/拒绝策略可解释，显式清除与缺字段可区分；旧正式按自身快照展示；错误或旧页写入不悄悄重置新设置。

**证据**：[E06 保存字段与缺省语义](../../history.md#lesson-e06)、[E07 长期与当天迁移](../../history.md#lesson-e07)、[E08 旧页跨版本保存](../../history.md#lesson-e08)、[E10 旧人数快照与主动例外的区别](../../history.md#lesson-e10)。
