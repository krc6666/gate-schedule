# 分则：验证与交付

本页为有效方法；先读[通则与索引](../需求理解与验收经验.md)。证据不足时明确范围，继续能独立完成的调查和验证。

<a id="v01"></a>

## V01 现场身份和证据范围

**检索词**：现场、截图、日期、版本、人员、岗位、旧副本、测试通过仍不对。

**适用**：用户展示结果与测试不一致，或只能取得一部分现场资料。

**易错**：用另一日期、相近目标、新建页面或旧保存副本代替当前现场；把源码新版当成用户页面已加载新版。

**做法**：核对日期、组别、来源/目标、实际设置、保存状态与运行入口；对象识别查[M02](概念与规则关系.md#m02)。记录哪些证据来自原现场、隔离副本、模拟和人工确认；缺资料时继续[V02](#v02)，保留现场证据缺口。

**完成标准**：结论能对应准确输入与实际入口；未取得的现场证据明确标注，模拟成功没有被表述为原截图已修复。

**证据**：[E09 26日截图与24日副本的边界](../../history.md#lesson-e09)、[E08 干净新页面遗漏旧标签页](../../history.md#lesson-e08)。

<a id="v02"></a>

## V02 可推翻自身理解的试验

**检索词**：根因、复现、失败测试、单变量、主动模拟、正反对照、整日竞争。

**适用**：排错、无法取得完整现场，或现有测试全部通过却无法解释用户反例。

**易错**：只复述算法理由；按旧实现编写预期；反复索要截图而不试验；构造例子时悄悄替换目标或消除真实竞争。

**做法**：按G01/G03先确定可见预期，构造能失败的最小输入，再一次只改一个条件作对照。现场不足时，从真实页面设置走完保存、重排、归档与重开；最小例子后加入整日需求和多人竞争，最后核对原配置。证据分界按[V01](#v01)。

预期从用户要求和原始输入独立推导；检查实际结果中哪些对象应存在，而不是照抄转换器或旧实现输出。相同机制影响多个入口时，按[D01](数据与配置.md#d01)逐项验证；只测新建数据不足以覆盖已有草稿、缓存、旧页及恢复后的状态。完整性方法见[V04](#v04)。

**完成标准**：能指出哪次失败暴露用户所说问题、哪项单变量验证原因；修复后原例和反向边界都通过，原缺失事实仍如实保留。

**证据**：[E09 主动模拟与整日原配置调查](../../history.md#lesson-e09)、[E03 兼职与缺人竞争反例](../../history.md#lesson-e03)、[E04 大件显示先失败再修复](../../history.md#lesson-e04)。

<a id="v03"></a>

## V03 实际使用入口交付

**检索词**：原入口、源码、成品、打包、安装、旧页面、缓存、上线、资料保持。

**适用**：行为或界面已修改，需要交付用户实际运行的程序。

**易错**：源码、构建或新测试页面通过就称交付完成；忽略原快捷方式、已打开的旧页面、后续归档和重新打开。

**做法**：识别真实入口及运行资源，按AGENTS既有交付流程验证隔离成品、备份更新和原入口；保留用户配置、人员、草稿与历史。升级同时检查已开旧页面的保存行为，并分别记录测试、安装、提交、推送和部署状态。

**完成标准**：原使用入口提供预期行为，资料保持有证据；旧页面不能按旧合同悄悄覆盖新设置；未安装或未上线明确说明，程序改变不能仅以文档完成替代。

**证据**：[E08 原入口旧页面保存问题](../../history.md#lesson-e08)、[E04 本地成品及开发入口分别核对](../../history.md#lesson-e04)。

<a id="v04"></a>

## V04 独立核对完整性与正确性

**检索词**：没报警却漏了、应有对象没生成、零错误、校验全绿、漏字段、漏记录、漏规则、静默遗漏。

**适用**：输入经过筛选、转换、合并、缓存或恢复后才生成对象、执行规则或产生输出；检查器可能只看已生成的内容。

**易错**：漏掉的对象没有进入检查范围，却把零报警当作完整正确；预期集合由待检查的转换结果反推，生成与验证一起漏掉同一项；用总数相等掩盖对象身份或数值错误。

**做法**：从业务要求和原始输入独立列出应处理的对象、应执行的规则及允许省略的条件，按身份和关键值比较预期与实际，解释每项缺失或额外内容。分别检查三件事：应有内容是否齐全、已有内容是否正确、故意破坏后能否发现。至少覆盖“应有却未生成”“已生成但数值/安排错误”“按规则允许为空或省略”；更换对象或受影响入口再验证。复用唯一领域事实，不另抄一套业务规则，也不拿同一转换的输出给自己作证。

例如需求存在却未生成任务、导出漏掉必需字段、恢复漏掉应保留记录、权限或规则被过滤后未执行，都属于同类检查；具体哪些内容必须保留、何时生效仍由各自业务合同决定。

**完成标准**：能用“预期对象/关键值、实际对象/关键值、差异及原因”证明完整性；合法省略不误报，故意遗漏和错误值能被相应检查或回归发现；证据覆盖本次影响面，未验范围明确。不以文档更新或一组测试通过承诺未来绝不再犯。

**证据**：[E06 保存入口漏消费字段](../../history.md#lesson-e06)、[E10 有需求却未生成任务使校验失明](../../history.md#lesson-e10)、[E11 用户要求推广到所有同类流程](../../history.md#lesson-e11)。导出、恢复和权限为方法示例，不冒称这些功能都已发生相同事故或完成全仓审计。
